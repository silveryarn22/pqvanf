Stick Set Privacy Policy

Margaret Dalton

Stick Set keeps each line on this iPhone. The stick measure is 6. Each sort is only width 1, 2, or 3. A sort joins the line when its width fits the space left, and the space left drops by that width. A wider sort stays outside and the line does not change. Space left 0 means the line is justified. The last sort can be pulled back only while the line is not justified. After the line is justified, placing and pulling do nothing. The app does not collect data, does not use an account, and does not include purchases. Sharing uses the system share sheet and only sends the line name and whether the line is justified.
